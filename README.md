# Strata Map — نقشه و مترو تهران

نقشهٔ تمیز و نقشه‌محور با مسیریابی مترو، بی‌آرتی، پیاده، دوچرخه، خودرو و موتور. PWA است و روی گوشی نصب می‌شود.

## انتشار روی GitHub Pages
1. همهٔ فایل‌های این پوشه را در ریشهٔ یک مخزن بگذارید (فایل `.nojekyll` هم باشد).
2. Settings ← Pages ← Source: `Deploy from a branch` ← شاخهٔ `main` و پوشهٔ `/ (root)`.
3. آدرس `https://USER.github.io/REPO/` را باز کنید. یک بار صفحه را دوباره بارگذاری کنید تا Service Worker فعال شود، بعد از منو «ذخیرهٔ نقشهٔ تهران برای آفلاین» را بزنید.

حالت آفلاین و نصب برنامه فقط روی https (یا localhost) کار می‌کنند، نه با باز کردن مستقیم فایل.

## برنامهٔ حرکت قطارها
مقدار فاصلهٔ قطارها و ساعت کار در `index.html`، ثابت `SCHED`، **تقریبی** است و برنامهٔ رسمی نیست. قبل از انتشار عمومی با داده‌های رسمی مترو/بی‌آرتی جایگزینش کنید. اگر منبع رسمی نداشتید، در اپ هم همین را «تقریبی» نشان بدهید.

## نکته‌های مهم برای استفادهٔ عمومی
- مسیریابی (`routing.openstreetmap.de`)، جستجو (`photon.komoot.io`)، بی‌آرتی (Overpass) و کاشی‌ها (OpenFreeMap) سرویس‌های رایگان با محدودیت مصرف‌اند. برای ترافیک جدی سرور خودتان را بگذارید.
- مسیریابی جاده‌ای و جستجوی مکان آفلاین کار نمی‌کند؛ مسیر مترو، ایستگاه‌ها و نقشهٔ ذخیره‌شده کار می‌کنند.
